# Harr's Painting and Services — website mockup

Local preview built from the master painting template (TanStack Start + Tailwind).

```bash
npm run dev          # preview
npm run typecheck && npm run lint && npm run build
npm run check        # pre-launch checklist
```

- Business facts, SEO and form provider: `src/config/site.config.json`
- Service copy: `src/lib/services-data.ts`
- Before/after project photos: `src/lib/projects.ts` (add photos to `public/projects/`)
- Estimator options: `src/lib/estimator-data.ts`
